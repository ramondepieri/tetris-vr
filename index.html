Calibração dos Óculos

Coloque os óculos 3D. Para calibrar o Olho 1, feche o olho esquerdo (lente vermelha) e ajuste o slider até o quadrado vermelho desaparecer no fundo preto através da lente ciano. Depois, para calibrar o Olho 2, feche o olho direito (lente ciano) e ajuste o slider até o quadrado ciano desaparecer através da lente vermelha. O objetivo é minimizar o "vazamento" da cor destinada ao outro olho; por isso o slider pode chegar a preto.

🥽 Modo VR — lado a lado

Para usar com um visor de celular (tipo Cardboard). A tela é dividida ao meio: o olho esquerdo vê a metade esquerda e o direito vê a metade direita, em cores completas, sem óculos 3D. Como no modo normal, um olho vê só a peça que cai e o outro só a pilha de peças, então os dois precisam trabalhar juntos. Use o celular na horizontal.

Fluxo: ajuste aqui com o celular na mão → toque em Iniciar → encaixe no visor. Dentro do visor, com um controle Bluetooth, Start abre o menu de ajustes. Sem controle, dá para jogar por toque: deslize para os lados para mover, deslize para baixo para descer, toque para girar e toque com dois dedos para pausar.
